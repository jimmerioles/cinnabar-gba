# Brand assets

| File | Purpose |
|---|---|
| `icon.png` | 512×512 project icon: a pixel-art GBA with a cinnabar crystal on screen. |
| `banner.png` | 1280×640 hero banner for the README and GitHub social preview. |

The artwork is original to Cinnabar GBA and follows the repository's MIT license.

The wordmark is set in **Press Start 2P** by CodeMan38, used under the
[SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/pressstart2p/OFL.txt).
The font file is not committed; only the rendered PNGs are.

To use the banner as the repository's social preview, upload
`docs/brand/banner.png` in the repository settings.
